# Kolmogrov fixed-width channel seam

Status: **OBSERVED disabled experimental adapter; production profile and live
service admission remain unselected**.

The engine reserves `internal/similarity` for the fixed-width perceptual-hash
family being researched in `../kolmogrov/`. It now contains a native Go
dogfood adapter for the sealed coupled-history guidance in
`HISTORY_HASH_ENGINE_CONTRACT_001.md`. It contains no approximate-nearest-
neighbor graph, learned distance, or fusion weight, and the service continues
to advertise no fuzzy feature.

## GIVEN constraints

- Every sketch is disposable and versioned by family, revision, byte width,
  and parameter digest.
- Every sketch and returned candidate anchors to an exact catalogue object,
  observed path, root, and committed generation.
- Candidate count and elapsed work are caller-bounded.
- Channel scores and named contributions remain separate evidence. They do not
  become identity and do not outrank exact facts merely by being available.
- A configuration change permits independent erase/rebuild of this channel.

## Transfer gate

Kolmogrov may enter an experiment build only after it supplies a pinned
configuration, deterministic cross-platform vectors, collision/ambiguity
behavior, encoding cost, candidate-retrieval mechanism, resource bounds, and an
exact-catalogue verification path. It must then beat fixed-width and lexical
controls on the same judged File Manager workload. Until that evidence exists,
the service advertises no similarity feature and exact/lexical delivery does
not wait for it.

## Experimental transfer 001

**OBSERVED:** `internal/similarity` implements the literal-scalar radius-one
history-tuple profile as a disabled experiment:

- two explicit generation-random coordinates, 20 bits each, remain coupled in
  one private 40-bit key per complete deletion history;
- the rolling recurrence performs no descendant copy and deduplicates at most
  64 keys in fixed scratch;
- typed `n-1,n,n+1` posting plans use at most `2n+1` probes;
- candidate, posting-entry, probe, deadline, configuration, input-length, and
  partition-population limits fail with explicit terminal states;
- immutable liveness filters exact ordinals without rewriting dead postings;
- a linear fixed-scratch verifier classifies equality, substitution, adjacent
  transposition, insertion, and deletion and attaches digit, extension,
  boundary, structural, and explicitly labeled Go-simple-fold evidence;
- a checked immutable component file keeps postings off the Go heap behind a
  262,148-byte high-prefix range directory and a bounded one-MiB lazy cache;
- the direct builder sorts one exact-length partition at a time, caps scratch at
  32 MiB, writes each final posting once, and rejects a larger partition rather
  than silently exceeding the bound.

The Python-derived vector is frozen at
`testdata/similarity/history_tuple_reference_001.json`. The public E13
`ldfioia`/`kbmedfa` collision remains a required negative test: the hash returns
both and the exact verifier removes the nonrelation.

The experiment does not freeze tuple bytes as an ABI, wire the projection into
the live manifest/public query service, require folded or structural filtering,
rank candidates, support radius two, or select the polynomial family. Its
component result is recorded in `results/M5_KOLMOGROV_HISTORY_TUPLE_001.md`.

## Exact-generation service dogfood 002

**OBSERVED:** the persistent service now provides a private read-only lease on
one authenticated exact generation. The durable store opens and pins a second
bounded reader only when generation plus catalogue and segment digests still
match the live reader. The direct builder consumes exact filenames lazily by
ordinal, and full path/object anchors are decoded only for candidates that need
verification or return. No catalogue-sized `[]Input` mirror is required.

The disposable projection remains outside the exact manifest. Mutation,
same-cardinality generation rollover, cancellation, capacity rejection,
restart, corruption, read-only query, and exact-fallback behavior are exercised
in a disjoint `t.TempDir` sandbox. The 10,000-file same-corpus measurement is in
`results/M5_KOLMOGROV_SERVICE_DOGFOOD_002.md`.

This closes the exact-reader integration subgate only. Full-rebuild write cost,
atomic similarity publication, background pacing, liveness/dead-posting
rollover, compaction, judged controls, and public planner fallback remain open.
