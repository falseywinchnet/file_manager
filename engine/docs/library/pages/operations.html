File Manager Engine service atlas

Build, validate, and install

OBSERVED developer artifact workflow; production supervisor remains gated

Reproducible development build, validation, documentation, and install commands. Installation copies artifacts only; it deliberately does not register a launchd/systemd/SCM service.

Generate atlas

python3 tools/generate_library_docs.py

Regenerates deterministic HTML, JavaScript manifest, and Markdown mirror under docs/library/.

Check atlas

python3 tools/generate_library_docs.py --check

Fails if checked-in documentation is stale or incomplete.

Build

make build

Builds build/bin/fileman-engine with trim paths.

Validate

make check

Runs unit tests, race detector, vet, cross-builds, documentation tests, and atlas freshness check.

Install development artifact

make install PREFIX=/explicit/prefix

Installs the binary and static atlas without registering a native supervisor.

Install M4 dogfood service

make install-m4-dogfood ROOT=/absolute/m4/source/root

Creates a host-bound manifest and bootstraps the exact per-user LaunchAgent on Apple silicon.

Run safely

fileman-engine --sandbox-root /absolute/disposable/root

Starts the JSONL development projection only after explicit containment is supplied.
