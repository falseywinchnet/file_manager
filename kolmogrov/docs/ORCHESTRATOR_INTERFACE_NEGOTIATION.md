### Disposition of proposal 001

Kolmogrov accepts the proposed transfer-bundle categories with these
counterproposals:

1. The canonical configuration descriptor is semantic authority; a digest is a
   compact identity/check, not a substitute for the descriptor or evidence.
2. ORC-KOL-001 is an internal engine/library semantic seam, not a separately
   callable Kolmogrov daemon. Orchestrator observes its availability and
   evidence through the registered engine contracts.
3. Candidate production and exact verification remain separate. A Kolmogrov
   positive is never an exact result and cannot omit the exact engine anchor.
4. Numeric jets and idempotent observable certificates are separate channel
   algebras. Their bytes, scoring, and failure states may not be fused into one
   undocumented distance field.
5. The first frozen artifact must be explicitly `lab`/`experimental`; it may
   open fake/reference adapters without advertising production similarity.

### Canonical interchange proposal

Use canonical UTF-8 JSON fixture envelopes containing the full configuration
descriptor, its compact configuration identity, symbolic input, exact object
anchor, ordered channel IDs, declared bit counts, lowercase hexadecimal bytes,
candidate-query limits, expected candidate anchors, raw channel evidence, and
terminal status. Hexadecimal is a fixture projection only; production engine
storage remains private.

The exact JSON canonicalization and descriptor-digest algorithms are accepted
as required fields but counterproposed for Orchestrator selection alongside the
common contract vocabulary. No checksum is mathematical evidence.

### Private implementation boundary

Keep dynamic-programming slabs, gap-polynomial representation, run-block
matrices, finite-field controls, phase generation, affine schedule compiler,
SIMD layout, allocators, posting representation, and language-native types
opaque. Explicit subsets, channel semantics, bounds, byte rules, evidence, and
configuration identity cross the seam; the generating implementation does not.

### Errors, bounds, cancellation, and migration

Kolmogrov proposes the terminal details `unavailable`, `unsupported_input`,
`configuration_mismatch`, `rebuild_required`, `budget_exceeded`, `cancelled`,
`corrupt_projection`, and `internal_failure`, mapped under ORC-COM-001.
Candidate count, posting work, elapsed work, and response bytes are bounded by
the stricter engine/session policy. Cancellation inherits the engine request
context. Continuations bind to engine generation, configuration identity, and
normalized query plan.

Kolmogrov projections are disposable. An incompatible semantic descriptor is
never read as an older compatible hash; the engine reports fallback and rebuild
state. No in-place migration of address bytes is promised in round 001.
