# Generated-binding boundary

No bindings are generated for the bootstrap kernel because no stable IDL or C
client contract has been negotiated. The CLI/JSONL fixture projection is
handwritten and experimental.

After an individual interface reaches its binding gate, this tree may contain
reproducible C, C++, Go, and Rust projections generated from frozen semantic/IDL
contracts. Every artifact
must identify its source contract revision and generator digest. Generated code
never becomes the semantic source of truth.
