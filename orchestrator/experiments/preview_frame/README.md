# Preview frame laboratory

Disposable provider-independent fixture for
[`SELECTED_PREVIEW_FRAME_DRAFT.md`](../../spec/SELECTED_PREVIEW_FRAME_DRAFT.md).
No daemon/frontend linkage, codec, file authority or production transport.
Rust 2021, minimum Rust 1.87, no crate dependencies. The C++20 producer emits one
fixed 88-byte golden frame. The Rust CLI validates exact received pixels.

The library checks a fixed header before allocating at most 4 MiB of live raster
storage, accepts fragmented input, rejects invalid/trailing input, and transfers
ownership only at successful EOF validation. These checks do not establish peer
authentication, source identity, process exit, color correctness or GUI delivery.
The canonical draft describes those remaining boundaries and allocation scope.

On Shadow select the existing toolchain read-only, with one local compiler job:

```powershell
. ./tools/Enter-WindowsToolchain.ps1
cargo fmt --manifest-path orchestrator/experiments/preview_frame/Cargo.toml -- --check
cargo test --manifest-path orchestrator/experiments/preview_frame/Cargo.toml --locked --offline --jobs 1 --target-dir orchestrator/.build/preview-frame
cargo clippy --manifest-path orchestrator/experiments/preview_frame/Cargo.toml --locked --offline --all-targets --all-features --jobs 1 --target-dir orchestrator/.build/preview-frame -- -D warnings
cmake -S orchestrator/experiments/preview_frame/fixture -B orchestrator/.build/preview-frame-fixture -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build orchestrator/.build/preview-frame-fixture --parallel 1
```

The dedicated workflow pins Rust 1.87 and pipes the native C++ producer into the
Rust consumer on Windows, macOS and Linux with shell pipe-failure propagation.
Shell pipelines here orchestrate fixed test executables, not product commands.
Use raw native pipe bytes, not text encoding conversion. The Windows producer
sets stdout binary mode. Generated bytes contain no personal filesystem data.

[`PROGRAMMING_HOUSE_STYLE.md`](../../../planning/PROGRAMMING_HOUSE_STYLE.md)
applies completely to the library, tests, producer, consumer and authored tools.
Typed Rust destructuring/derives and named tail expressions are Rust syntax;
the C++ spelling table applies to the producer. No generated-profile restrictions
are imposed on this ordinary authored fixture. Functional, lint and independent
semantic source review are recorded separately in `results/`.

The additional `check_jpeg` binary consumes the standalone JPEG experiment's
actual output, with expected EXIF orientation and `plain`/`linear` color mode.
It checks the scaled dimensions and four interior color anchors using its own
orientation table and scalar sRGB transfer curve. The JPEG workflow owns that
16-case cross-process comparison; evidence is in
`../../../frontend/results/2026-10-04-jpeg-frame/README.md`. This binary does not
open input files, launch the producer or provide process supervision.
